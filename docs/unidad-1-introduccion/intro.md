# Introducción a los Sistemas Operativos

## ¿Qué es un Sistema Operativo?

Un sistema operativo (SO) es el software que actúa como intermediario entre el usuario y el hardware de la computadora...

## Funciones principales

- Gestión de procesos
- Gestión de memoria
- Gestión de archivos
- Gestión de dispositivos de E/S
